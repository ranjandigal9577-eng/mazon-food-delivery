# MAZON launch checklist

## Before launch
- [ ] Domain + HTTPS
- [ ] Production PostgreSQL
- [ ] Razorpay production credentials + webhook secret
- [ ] Google Maps key restricted to domain (optional)
- [ ] SMS/OTP provider
- [ ] Push notifications
- [ ] Restaurant onboarding/KYC
- [ ] Delivery partner onboarding/KYC
- [ ] GST/tax/invoice rules
- [ ] Commission rules
- [ ] Refund/cancellation policy
- [ ] Privacy policy and terms
- [ ] Admin account created securely
- [ ] Remove development admin endpoint
- [ ] Backups and monitoring
- [ ] Security/rate-limit review
- [ ] Android AAB/Play Store setup if required
